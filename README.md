# تنبيهات السعر المتكررة كل خطوة سعرية (TradingView)

سكربت Pine Script يُصدر تنبيهاً تلقائياً كلما تحرّك السعر بمقدار محدد (مثلاً **100 دولار**)
صعوداً أو هبوطاً، ويصلك الإشعار على تطبيق **TradingView في الآيفون**.

> مثال: السعر الآن `61100`. عند بلوغ `61200` تنبيه، وعند `61300` تنبيه،
> وعند `61000` تنبيه هبوط... وهكذا بشكل متكرر تلقائياً.

الملف: [`recurring_step_alerts.pine`](./recurring_step_alerts.pine)

---

## 1) إضافة السكربت إلى TradingView

> ينصح بإنشاء الأندكيتر من الحاسوب أو موقع tradingview.com (محرر Pine غير متوفر داخل تطبيق الجوال)،
> ثم تشغيل التنبيه ومتابعته من الآيفون.

1. افتح [tradingview.com](https://www.tradingview.com) وافتح أي شارت (مثلاً BTCUSD).
2. من الأسفل اضغط **Pine Editor** (محرر باين).
3. احذف المحتوى وألصق كامل محتوى الملف `recurring_step_alerts.pine`.
4. اضغط **Add to chart** (إضافة إلى الشارت).

## 2) ضبط الإعدادات (تتحكم بكل شيء)

اضغط على إعدادات الأندكيتر (⚙️) وتحكّم بـ:

| الإعداد | الوظيفة |
|---|---|
| **مقدار الخطوة (دولار)** | كل كم دولار يصدر تنبيه (افتراضي 100). غيّره لـ 50 / 200 / 0.5 ... |
| **اتجاه التنبيه** | الاتجاهين / صعود فقط / هبوط فقط |
| **مصدر السعر** | السعر المستخدم في الحساب (الافتراضي: الإغلاق/السعر الحالي) |
| **تحديد سعر بداية يدوي** | لتبدأ الشبكة من سعر تحدده أنت بدل السعر الحالي |
| **سعر البداية** | مثلاً 61100 (يعمل عند تفعيل الخيار أعلاه) |
| **تكرار التنبيه** | مرة لكل شمعة / عند الإغلاق / كل تحرك فوري |
| **إظهار خطوط المستويات** | رسم خطوط الهدف صعوداً/هبوطاً والمرجع |

> لتغيير **العملة**: غيّر رمز الشارت نفسه (الزوج)، وسيعمل السكربت على أي عملة/سهم.

## 3) إنشاء التنبيه ليصل للجوال

1. على الحاسوب: اضغط زر التنبيه (⏰ Alert) أو `Alt+A`.
2. في **Condition** اختر اسم الأندكيتر، ثم اختر **Any alert() function call**.
3. في **Alert actions** فعّل **Notify on app** (إشعار على التطبيق).
4. في **Expiration** اختر **Open-ended** (مفتوح) حتى يستمر التنبيه.
5. اضغط **Create**.

## 4) استقبال الإشعار على آيفون

1. ثبّت تطبيق **TradingView** من App Store وسجّل بنفس الحساب.
2. من التطبيق: **الإعدادات → Notifications** وفعّل **Push notifications**.
3. من إعدادات الآيفون: **Settings → Notifications → TradingView → Allow Notifications**.
4. تأكد أن صوت/الشارة (Badges) مفعّلة لتسمع التنبيه.

عند تحقق أي خطوة سعرية سيصلك إشعار مثل:
`🔼 ارتفع السعر إلى 61200 (+100)` أو `🔽 انخفض السعر إلى 61000 (-100)`.

---

## ملاحظات مهمة

- التنبيه يعمل **حتى لو الجوال مغلق أو التطبيق في الخلفية** لأنه يُعالَج على خوادم TradingView.
- خيار "**مرة لكل شمعة**" هو الأدق وأقل إزعاجاً؛ أما "**كل تحرك فوري**" فيرسل بسرعة لكن قد يتكرر.
- لكل عملة/زوج أنشئ تنبيهاً منفصلاً (يمكنك تشغيل عدة تنبيهات بأسعار وخطوات مختلفة).
- في الحساب المجاني عدد التنبيهات النشطة محدود؛ الخطط المدفوعة تتيح عدداً أكبر.
